## 修正

- `conversation.go` 中 `create_file`／`overwrite_file` 的校验分支与候选生成分支各重复一次；首个分支已返回，后续重复分支不可达。删除不可达代码，不改变行为。
- Agent API 文档缺少整份计划拒绝接口；已按服务端实现补上版本校验、响应状态和 Shell 暂存清理行为。
- Release workflow 原先在构建与依赖测试期间持有 `contents:write`。现拆为只读验证任务和独立发布任务；发布任务只下载归档、校验 SHA-256 与标签目标后创建 Release。
- 7-Zip、图片解码器和 ffmpeg 子进程改用统一安全启动入口：最小环境不继承模型密钥，Linux 下通过 `setpriv` 清除 ambient capabilities。
- 归档工具隔离不可用时 API 返回明确的 `503`，不再误报为通用服务错误；读、写错误映射均有回归测试。
- 进度页列出当前候选、授权门槛和下一步；验收页只保留证据与未覆盖项，导航只做入口。ADR-0004 的已决定状态与章节标题已统一。
- `.gitignore` 排除的私有维护清单保留原样，不从公开文档引用。
