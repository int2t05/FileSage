# 纯净审计

**日期：** 2026-10-24　**范围：** Agent、Shell、上传续传、发布流程和项目文档

## 修正

- Agent 与审批流程补充并发状态回归；工具子进程使用最小环境，归档工具隔离不可用时明确返回 `503`。
- Release 工作流将只读验证与发布权限分开；发布前校验归档哈希和标签目标。
- 部署指引用显式条件拒绝复用已存在的解包、暂存和回退路径，不依赖 `set -e` 捕捉 `&&` 链中的失败。
- Release 打包器拒绝 `web`／`web/dist` 符号链接、构建树中的非普通文件、软链接二进制输入及归档／校验软链接目标。
- 上传确认丢失时查询持久发布状态，避免已发布文件误报失败；分块上限为 64 MiB，按服务端偏移恢复。
- 主 CI 与 Release 验证将 Race 检查串行扩展至文件发布协调器、SQLite 与 TUS 上传路径，降低数据状态竞态漏检并限制并发内存峰值。
- 文档导航、进度、验收证据和 ADR 各自维护；不公开链接本地私有验收清单。

- 部署路径已存在时的停止条件通过只读 Bash fixture 验证，脚本按预期非零退出。
