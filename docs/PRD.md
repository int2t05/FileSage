# FileSage 产品需求

日期：2026-10-15。状态：**需求成熟（用户确认）**。首期范围、业务规则和验收标准已确认；已选技术基线与实施验证状态见[技术决策与 ADR](TECH.md)。本文描述需求，不代表功能已经实现或实测。

## 1. 产品定位与范围

面向个人使用的 Linux 原生文件管理系统，通过局域网内的电脑和手机浏览器上传、管理、阅读文件，由 Agent 分析并提出操作方案，经人工审批执行。

项目变量指定一个管理根目录，直接使用已有文件和目录结构，文件夹就是类别。无账号和密码，能访问服务的设备具有相同操作能力。界面默认中文，手机核心流程不依赖右键或拖拽。

**首期全部包含**文件管理与传输、照片和媒体浏览、文档阅读、文本编辑、归档管理、EPUB 阅读、Agent 文件操作与审批、任务及操作历史。

**不做**多人权限、外网分享、手机自动备份、客户端同步、云盘接入、磁盘池管理、标签或虚拟相册、全文或向量搜索平台、人脸与视觉相似识别、旧内容备份、前端 Office 编辑、全格式音视频转码、未经用户审计计划的 Agent 写操作。

## 2. 文件管理与传输

| 能力       | 首期要求                                                                                                                                                     |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 浏览与搜索 | 目录导航、面包屑、列表／缩略图、详情、排序、隐藏文件切换、大目录按需加载；按名称和相对路径搜索，限定目录或递归范围，按类型、大小、修改日期及可读拍摄日期筛选 |
| 文件操作   | 新建文件夹、复制、移动、重命名、批量操作及批量重命名；支持跨文件系统移动                                                                                     |
| 上传       | 手动多文件、文件夹选择及拖拽，保留目录结构；支持大文件、进度与速率、暂停、取消、失败重试和续传；不删除手机或存储卡源文件                                     |
| 下载       | 下载原件，支持单文件断点下载；多文件和目录打包下载                                                                                                           |
| 同名与覆盖 | 上传及普通复制／移动默认加数字后缀；覆盖必须作为明确操作，不能静默替换                                                                                       |
| 删除与恢复 | 普通删除进入回收站，可恢复；永久删除和清空回收站单独确认，执行后不可恢复；恢复不覆盖后来产生的数据                                                           |
| 权限与属主 | 可查看和修改，遵循实际运行权限，权限不足明确报错                                                                                                             |
| 软链接     | 可创建、展示及跟随根目录内链接；越界禁止跟随，循环和失效明确提示；操作区分链接与目标，删除链接不删目标                                                       |
| 压缩与解压 | 浏览和解压 ZIP、7z、RAR、TAR／TAR.GZ，创建 ZIP、7z、TAR／TAR.GZ；损坏、不支持或无法解密时说明原因                                                            |

上传速率优先，同时保证完整性、同名不覆盖和可靠续传。网络中断、刷新或服务重启后可恢复进度；需要重新选择本地文件时提示，不能复用不同内容的旧进度。未完成文件不能显示为上传成功。

跨文件系统移动须复制并校验成功后再删源件。任务显示实际路径、成功、失败、未开始和部分完成结果；空间、权限或设备不可用不能伪装为成功或空目录。服务器其他工具修改文件后，列表、搜索和预览可刷新或重建。

所有入口均受根目录边界约束；链接、解压条目和命令不能越界。链接别名不当作独立副本，服务自身状态和审计记录不作为用户整理对象。

## 3. 阅读与编辑

支持格式必须有浏览器内的实际阅读能力，不能只给下载链接。阅读、预览及分析不改写原件；无法解析仍可管理和下载，并说明原因。

| 类别                       | 首期体验                                                             |
| -------------------------- | -------------------------------------------------------------------- |
| JPEG、PNG、WebP、GIF、AVIF | 缩略图、大图、缩放、连续浏览、方向修正和可读 EXIF                    |
| HEIC／HEIF、RAW            | 可浏览预览；覆盖 DNG、CR2、CR3、NEF、ARW 样本，无法解码明确提示      |
| 视频／音频                 | 视频缩略图、播放和进度拖动；播放浏览器支持的常见音频                 |
| PDF                        | 分页、缩放、页码、文本选择、文内查找、已有书签目录导航               |
| Markdown                   | 渲染／原文切换、标题目录、根目录内相对图片、编辑保存                 |
| 文本／代码                 | 编码说明、行号、语法高亮、查找、编辑保存；超大文件限制明确提示       |
| DOCX                       | 正文、图片、表格、分页及可解析标题导航，前端只读                     |
| XLSX／CSV／TSV             | 行列阅读，XLSX 工作表切换，展示已有值及可用公式结果，前端只读        |
| PPTX                       | 幻灯片列表、翻页、全屏逐页播放，前端只读                             |
| EPUB                       | 章节目录、翻页／滚动、字号、阅读位置；不承诺解锁加密保护             |
| 压缩包                     | 目录树、条目名称及大小，包内支持格式可阅读；仅明确解压时写入指定目录 |
| 其他／旧办公格式           | 详情、管理与下载，预览能力按支持矩阵说明                             |

Office 保证常见样本的图文表格可读，不承诺复杂排版、对象或动画完整还原；不要求宏执行或公式重算。不能用统一转 PDF 代替工作表、章节和包内导航。

手动编辑保存写回真实文件，未保存离开须确认。文件内脚本、宏和外部资源不得自动执行或加载；转换、OCR 和提取有状态、错误及重试入口。

## 4. Agent 与审批

Agent 仅在根目录内操作，包含创建文件／目录、分类归档、复制、移动、重命名、编辑内容、覆盖、普通／永久删除、压缩／解压、权限／属主、软链接和 Shell 命令。

用户通过自然语言描述目标，可从所选项目、当前目录或递归范围开始。Agent 先与用户澄清目标、范围和处理规则；用户确认分析任务及数据范围后，模型才读取文件并生成方案。常用任务包括按拍摄日期归档、按文档内容分类、语义重命名和完全重复识别，不限制其他文件任务。日期以元数据为依据；重复须内容校验，不凭名称、大小或视觉相似判断。文档支持文字提取和主动触发的中英文 OCR，显示读取范围及失败项。

模型可接本地或指定远程服务，分析前展示服务及数据范围，密钥不暴露；模型不可用不影响基础文件管理。Office 前端只读，Agent 可经审批修改内容。

统一流程为：**自然语言对话 → Agent 澄清 → 用户确认任务与数据范围 → 按任务复杂度形成计划 → 用户审计计划 → 顺序执行 → 查看结果**。

- 计划保持最少必要步骤：简单任务简短呈现，复杂任务拆成可独立预检、顺序执行的步骤。首期不支持模型在执行中动态追加依赖步骤；无法预先安全确定的任务继续澄清或拒绝执行。执行时突出当前步骤的目的、状态和结果；路径、命令、差异等详细信息按需展开。
- 设置提供 `bypasspermission` 模式，默认开启。每份计划在用户审计时固定当时模式：开启后，用户确认计划即顺序执行所有步骤；关闭后，每一步均等待用户显式执行。设置变更只影响之后审计的计划。
- 所有写操作仍须先审计并确认计划；bypass 只跳过逐步确认，不跳过计划门禁、根目录限制、状态校验、冲突处理和审计。
- Agent 工具按有界、类型化的步骤接入，例如文件搜索／读取／写入／归档及 Bash。工具说明用途和影响范围，由服务端校验输入、权限与文件状态并记录执行结果；新增工具复用同一计划、逐步执行和审计机制，不动态加载任意插件。
- Shell 计划显示命令、工作目录和可核实的文件影响；命令只在隔离暂存区运行，差异纳入计划审计和步骤结果。隔离或差异校验失败时停止，不直接修改原目录。
- 永久删除在计划中清楚标记不可恢复，并要求用户明确确认；执行结果可查看、可停止。中断或重启不能重放已完成步骤，未完成步骤按当前模式等待确认或恢复。

手动操作走正常业务确认，删除、覆盖、权限变更等必要确认即可，不进入 Agent 审批清单。

**不保留旧内容**，编辑、覆盖和永久删除后不能恢复旧内容；历史保存指令、操作说明、路径、批准及结果，不保存可还原旧内容的全文或差异。移动、重命名及回收项可在当前状态允许时恢复。

## 5. 并发与冲突

上传、阅读、手动编辑和 Agent 可同时进行，不同文件不互相阻塞。同一文件及软／硬链接别名统一协调，同一时刻只能有一个写任务提交，等待后仍须校验状态。

| 场景                         | 必须行为                                                           |
| ---------------------------- | ------------------------------------------------------------------ |
| Agent 修改正在阅读的文件     | 不显示半写内容；更新后提示加载新内容，旧预览不能冒充当前内容       |
| Agent 修改正在编辑的文件     | 保留未保存草稿并提示；保存冲突时提供重新加载或另存为，不静默覆盖   |
| 同名上传、目录与子项操作重叠 | 同名分别改名保存；目录及子项协调等待或暂停，重新校验路径和状态     |
| 外部工具修改、删除或替换     | 发现变化则阻止旧操作，报告失败或部分完成；不承诺应用能锁住外部工具 |

后台预览、OCR 和 Agent 不得阻塞传输和浏览。具体性能基准、文件规模、资源限制及并发实现由技术方案定标，不在本 PRD 声称已达标。

## 6. 验收标准

| 验收项     | 可观察结果                                                                                         |
| ---------- | -------------------------------------------------------------------------------------------------- |
| 原生管理   | 已有目录直接可用，界面与真实文件一致，全部管理操作及外部变化刷新可用                               |
| 传输       | 电脑／手机、文件／文件夹、大文件及批量传输可用；中断、重启、重试、同名和空间不足无静默覆盖或假成功 |
| 阅读编辑   | 第 3 节各类真实样本可读；工作表、章节、PPT 和包内导航可用；编辑正确保存并保留冲突草稿              |
| Agent 操作 | 对话可澄清任务并在用户确认范围和数据使用后分析；计划按复杂度组织并经用户审计；默认连续执行，关闭 bypass 后逐步确认；步骤和记录状态一致 |
| 并发恢复   | 重现第 5 节全部场景；中断不重放完成项，回收可恢复，内容覆盖及永久删除不可恢复                      |

交付须有可运行 Linux 部署、配置说明、格式支持矩阵、真实验收记录及已知限制。测试使用真实文件、文件系统、解析工具和模型调用，测试代码放在 `test/`。

需求依据：[竞品调研](../reference/research.md)、[技术覆盖与待验证事项](../reference/technical-coverage.md)。后续技术设计、性能目标和实施效果需分别审计与验证，不改变本文已确认的需求基线。
