# FileSage 产品需求

**状态：**需求基线已确认　**范围：**个人自用 MVP

## 产品目标

在 Linux 服务器上以原生文件系统管理个人文件，通过可信局域网浏览器访问。项目变量指定真实管理根目录；现有目录即类别，SQLite 只保存可重建索引和任务元数据。

## 首期范围

- **文件管理：**浏览、搜索、排序、筛选、批量操作、回收站、权限查看与修改；列表／网格、排序和隐藏文件偏好保存在浏览器本地；永久删除单独确认；按真实目录组织，不引入虚拟分类。
- **传输：**手动上传文件和文件夹，支持大文件、服务重启后续传、暂停、重试与目录结构；同名自动改名，覆盖必须明确确认。跨文件系统移动先复制并校验，再删除源文件。
- **阅读：**支持图片、视频／音频、PDF、文本／Markdown、DOCX、XLSX、CSV、PPTX、EPUB 和常见归档。Office 前端只读；无法解析时仍可下载原件并说明原因。格式细节见[阅读器 ADR](design/adr/0005-reader-rendering.md)。
- **Agent：**同一对话可多轮交流；模型每轮获得最新文件索引摘要，可自主搜索元数据并调用已登记工具。归档照片可从根目录自动发现，无需手填路径。模型按复杂度组织计划；每份写入计划均由用户审计。`bypasspermission` 默认开启，用户确认计划后自动逐步执行；关闭后每步等待确认。Shell 支持任意 Bash 语法，在隔离暂存区运行并审阅差异后统一提交。
- **并发：**不同文件可并行；同一文件及软／硬链接别名的写入须协调并复核状态。冲突停止并说明结果，不静默覆盖，不把部分完成报告为成功。

## 安全与边界

- 所有读写限定在管理根目录内；软链接可展示和跟随，但不得越界。
- 仅面向本机或可信局域网。首期无登录、密码和 HTTPS；可访问服务的设备拥有相同文件操作能力。
- Agent 对话发送给用户配置的模型。只有用户确认分析范围后才读取并发送相应文件正文；审计记录不保存正文或可还原旧内容。
- 删除原件、云盘、多人权限、外网分享、手机自动备份、前端 Office 编辑及未经用户审计的 Agent 写入不在首期范围。

## 验收

在 Linux 原生文件系统上验证文件管理、跨盘操作、断点续传、阅读、Agent 审批与冲突处理。界面适配手机浏览器；用户可自行完成实体设备与真实文件验收。技术实现和验证边界见[TECH](TECH.md)与[验收摘要](ACCEPTANCE.md)。
