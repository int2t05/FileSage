# FileSage v1.0.0

FileSage is a self-hosted file manager for Linux that works directly with existing directories and disks through a browser on a trusted local network.

## Highlights

- Browse, organize, preview, and transfer files without importing them into a cloud or database.
- Resume large uploads after network interruptions or service restarts.
- Continue multi-turn Agent conversations, review a complete plan, then execute with the configured approval mode.
- Review isolated Shell changes before they are committed to managed files.
- Use an SQLite index that can be rebuilt from the filesystem.

## Install

Download the Linux amd64 archive and its `.sha256` file, verify the checksum, and follow the [deployment guide](../operations/deployment.md).

## Operating boundary

FileSage has no login or HTTPS. Run it only on a trusted local network; any device that can reach the service can manage its files. Independent-host restore and user testing with personal files and a physical phone have not been completed.
