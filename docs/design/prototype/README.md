# FileSage React 交互原型

本地可运行的设计原型，覆盖文件浏览、照片时间线、Agent 操作审批和任务状态，并提供桌面／手机视口切换。它使用示例数据；上传、审批和文件动作只改变页面演示状态，不连接服务端，也不读写真实文件。

在本目录运行：

```sh
npm ci
npm run dev
```

Vite 会在本机 `127.0.0.1:5173` 提供预览。生成静态构建可运行 `npm run build`，本地检查构建结果可运行 `npm run preview`。依赖版本固定在 `package.json` 和 `package-lock.json` 中。

原型用于设计审阅，不替代真实手机浏览器、键盘无障碍、上传、并发冲突或生产文件操作验收。
