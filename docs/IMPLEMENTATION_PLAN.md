- 主线 CI 的 Go 测试、race、`go vet`、漏洞扫描、构建、Web E2E 和 Linux 发布包冒烟全部通过；其余验收证据见[验收记录](ACCEPTANCE.md)。

## 下一步

| 状态 | 工作 | 下一步与完成条件 |
| --- | --- | --- |
| 需低负载环境 | 持续负载与真实网络 | 在低 I/O 时段或独立主机完成小时级负载、分设备压力与断网续传；全程记录停止条件并核对文件哈希。 |
| 需独立主机 | 异机恢复 | 在另一台 Linux 主机和独立介质恢复文件与数据库；验证服务启动、SQLite 完整性和文件哈希。 |
| 需代表性样本 | 真实文件验收 | 用真实文档、扫描件和媒体文件检查阅读、编辑、OCR 与 Agent；记录不支持格式和失败样本。 |
| 待用户验收 | 实体手机 | 检查浏览、上传、阅读和 Agent 主流程；320／360／390 CSS px 自动化检查已通过。 |
| 未开始 | 稳定版发布 | 关闭适用的验收项，更新版本说明，核对发布包、附件和 SHA-256 后再打版本标签。 |

**边界：** 当前主要待办依赖低负载窗口、独立主机、真实样本或用户设备。FileSage 不提供账号认证或 HTTPS 终止，仅用于可信局域网。
