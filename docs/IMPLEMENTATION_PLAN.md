## 已完成

- Linux 构建、全量测试、race、漏洞检查、Chromium E2E 和 Linux 安装包冒烟。
- 双卷文件操作、跨卷移动、删除恢复和服务重启检查。
- 20 GiB 上传重启续传、20 GiB 下载与 Range、72 GiB 并发回环传输；结果均通过哈希核验。
- Agent 多轮对话、计划审批、工具执行和同会话续聊；320／360／390 CSS px 窄屏自动化检查。
- 合成 FileSage 数据从系统盘备份到 `/home` 盘，再从备份启动服务；SQLite 完整性与读取结果通过。此项未覆盖生产数据或另一台主机。
