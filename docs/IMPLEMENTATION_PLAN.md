# FileSage 项目进度

**更新：** 2026-10-22　**阶段：** 公开 MVP；尚无稳定版 Release。

本页是进度与待办的唯一入口。[验收证据](ACCEPTANCE.md)记录已测范围，[PRD](PRD.md)定义需求，[TECH 与 ADR](TECH.md)说明实现和边界。

**当前基线：** 生产服务运行 `8af7ca8`，该版本[主线 CI 已通过](https://github.com/int2t05/FileSage/actions/runs/39792042997)。服务健康，SQLite v30 完整性及外键检查通过；公开仓库仅有 `main`，开放 PR 为 0。服务器只保留当前程序和即时回退包。

## 交付状态

| 范围 | 状态 | 已验证 | 下一验收 |
| --- | --- | --- | --- |
| 文件管理与索引 | MVP 已实现 | 两块 ext4 磁盘；合成文件跨盘移动、校验及清理；创建、保存、删除后当前目录即时可见 | 剩余写入口的跨进程冲突与故障恢复 |
| 传输 | MVP 已实现 | 浏览器 6 MiB 上传／下载哈希一致；续传、改名、回收站及冲突有自动化覆盖 | LAN 大文件、断网与资源峰值 |
| 阅读、编辑与归档 | MVP 已实现 | 常见格式和沙箱用合成样本验证 | 真实业务文件的显示、编辑与失败样本 |
| Agent | MVP 已实现 | 持久服务真实模型执行经审批的合成文件改名及跨盘移动；同会话结果追问正确 | 其余工具的真实文件操作、并发与失败恢复组合 |
| 部署与开源 | 公开测试版运行中 | Go 1.27.3 构建、主线 CI、健康检查、SQLite 检查及双盘恢复合成样本 | 独立主机与异地恢复，再发布稳定版 |
| 手机 | 窄屏浏览器已检查 | 320／360／390 CSS px 布局 | 设备持有人用实体手机验收核心流程 |

以上“已实现”不等于稳定版验收完成；各项证据和限制见[验收范围](ACCEPTANCE.md)。
