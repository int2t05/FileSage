# FileSage 实施路线

本文只列尚未完成的验收事项。产品范围见 [PRD](PRD.md)，技术决策见 [TECH](TECH.md)，已完成证据与支持边界见 [验收台账](ACCEPTANCE.md)。

**当前状态：** 公开 MIT MVP，main CI 全绿，个人 Linux 服务器已部署；尚无稳定版 Release。

## 剩余工作

| 优先级 | 工作 | 完成条件 |
| --- | --- | --- |
| P0 | 独立主机部署与数据恢复 | Ubuntu 24.04 systemd 容器已验证首次安装、同版本升级、容器重启及文件与 SQLite 备份还原。仍需在独立 Linux amd64 物理主机完成安装和整机重启，验证真实挂载恢复及备份读写。真实数据卷故障只在隔离副本演练，不对生产根目录做破坏性测试。 |
| P0 | 文件竞争与故障恢复 | Linux race 回归已覆盖已打开写句柄原地改写时的移动、复制、回收站、文本编辑和重命名；关键用例重复 20 次通过。仍需覆盖外部进程与其他写入类型的提交窗口，验证冲突审计并记录原子性边界。 |
| P1 | Agent 持久流程 | 生产只读 API 核验 7/7 历史会话的任务／计划关联和审计事件；浏览器只读核验恢复 7 个会话摘要、4 条消息与计划面板，并在任务页看到 7 个 Agent 任务和 10 条审计事件。生产管理根目录的真实写入审批与执行仍待验收；写入继续在隔离根目录测试。 |
| P1 | 文件兼容性 | 用真实业务文件覆盖 Office、EPUB、RAW／HEIC、音视频编解码和归档格式，并记录设备、样本与明确失败边界。 |
| P1 | 依赖更新 | PR #1、#2、#4、#8、#9 已逐项审阅，差异无阻断；各 PR head 的 CI 全绿，PR #9 的 TypeScript 7 类型检查、构建和 273 项测试也在本地通过。分支落后 main，合并前更新分支并重跑 CI；合并后复核 main CI 与发布包。 |
| P1 | 性能与容量 | 在第二块 SATA 卷和局域网记录目录、搜索、并发请求、20 GiB 上传、OCR 和系统资源数据，按 [TECH 基线](TECH.md#已选性能与可靠性基线) 报告测试条件。 |
| 用户验收 | 手机体验 | 用户在实体手机验证导航、上传、阅读与 Agent 对话；浏览器窄屏检查继续作为回归。 |

## 发布门槛

通过 P0 验收，在干净主机完成安装与升级演练，复核发布包校验和、安装说明和未覆盖边界，再决定稳定版版本号及发布说明。当前服务仅面向本机或可信局域网，不提供用户认证或 HTTPS 终止。
