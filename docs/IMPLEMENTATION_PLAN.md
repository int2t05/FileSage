## 剩余工作

| 优先级 | 工作 | 完成条件 |
| --- | --- | --- |
| P0 | 独立主机部署与数据恢复 | Ubuntu 24.04 systemd 容器已验证首次安装、同版本升级、容器重启及文件与 SQLite 备份还原。仍需在独立 Linux amd64 物理主机完成安装和整机重启，验证真实挂载恢复、备份读写、可信 LAN 监听与防火墙边界。真实数据卷故障只在隔离副本演练，不对生产根目录做破坏性测试。 |
| P0 | 文件竞争与故障恢复 | Linux 回归覆盖原子覆盖遇到已打开外部写句柄时失败并保留来源、跨卷单文件和目录移动遇到外部写句柄或快照后改写时保留隔离来源、永久删除在审计期间遇到同路径替换或外部写句柄时保留文件并返回冲突，以及单项和批量重命名在审计写入后拒绝源替换、执行后核对目标身份。目标身份不符时记为待核查并停止后续批次；系统调用窗口仍不能与非协作外部进程原子比较身份，也不保证自动恢复。既有关键移动与删除用例重复 20 次通过；本轮重命名竞态纳入 Linux 全量 Go 测试和相关 race。隔离内核探针确认非协作外部打开请求可能在最后租约检查与删除间隙继续写入无路径链接的 inode；该边界已记录，外部直接访问不属于全局事务保证。Linux 全量测试、`httpapi`／`fsroot`／trash race 和全量 `go vet` 通过。仍需审计其余写入口和冲突恢复。 |
| P1 | Agent 持久流程 | 持久会话、计划与审计记录已在生产服务只读核验；真实文件写入审批与执行仍待验收，写入继续在隔离根目录测试。 |
| P1 | 文件兼容性 | 用真实业务文件覆盖 Office、EPUB、RAW／HEIC、音视频编解码和归档格式，并记录设备、样本与明确失败边界。 |
| P1 | 性能与容量 | 在第二块 SATA 卷和局域网记录目录、搜索、并发请求、20 GiB 上传、OCR 和系统资源数据，按 [TECH 基线](TECH.md#已选性能与可靠性基线) 报告测试条件。 |
| 用户验收 | 手机体验 | 用户在实体手机验证导航、上传、阅读与 Agent 对话；浏览器窄屏检查继续作为回归。 |

## 发布门槛

通过 P0 验收，在干净主机完成安装与升级演练，复核发布包校验和、安装说明和未覆盖边界，再决定稳定版版本号及发布说明。当前服务仅面向本机或可信局域网，不提供用户认证或 HTTPS 终止。
