# FileSage 项目进度

**更新：** 2026-10-22　**阶段：** 公开 MIT MVP；生产测试版运行中，尚无稳定版 Release。

本文是项目进度入口。验收证据见[验收范围](ACCEPTANCE.md)，产品范围见[PRD](PRD.md)，技术细节见[TECH 与 ADR](TECH.md)。

## 当前状态

- **代码：** 生产服务运行 `33fefd0`；`main` 最新为 `65eae56`，[主线 CI 通过](https://github.com/int2t05/FileSage/actions/runs/39781587889)。远端仅有 `main`，开放 PR 为 0。
- **服务器：** 服务健康，网页与文件 API 返回 HTTP 200；Agent 模型已连接；SQLite v30 完整性检查通过；测试临时文件和旧程序副本已清理，仅留即时回退包。
- **存储：** 已确认两块独立 ext4 磁盘；持久服务跨盘移动合成文件、校验内容并清理样本通过。
- **Agent：** 持久服务真实模型对话、审批执行与工具回执续聊已通过；测试只使用合成文件。
