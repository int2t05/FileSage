# FileSage 实施路线

本文只列尚未完成的验收事项。产品范围见 [PRD](PRD.md)，技术决策见 [TECH](TECH.md)，已完成证据与支持边界见 [验收台账](ACCEPTANCE.md)。

**当前状态：** 公开 MIT MVP，main CI 全绿，个人 Linux 服务器已部署；尚无稳定版 Release。

## 剩余工作

| 优先级 | 工作 | 完成条件 |
| --- | --- | --- |
| P0 | 干净主机部署与数据恢复 | 在独立 Linux amd64 主机完成首次安装、升级和整机重启；验证第二卷挂载、服务恢复及备份还原后的文件摘要、SQLite 完整性、外键和读写。真实数据卷只读、卸载、容量耗尽和介质故障仅在隔离副本上演练，不在生产根目录做破坏性测试。 |
| P0 | 文件竞争与故障恢复 | 用外部进程和已打开写句柄覆盖计划审阅、逐步执行与发布窗口；验证冲突时不会误覆盖、恢复状态可审计，并记录仍无法提供的原子性边界。 |
| P1 | Agent 持久流程 | 生产只读 API 已核验 7/7 历史会话的任务／计划关联和审计事件。继续验收浏览器中的历史会话、审批与执行回执展示及重启后续聊；所有写操作仍只在隔离根目录测试。 |
| P1 | 文件兼容性 | 用真实业务文件覆盖 Office、EPUB、RAW／HEIC、音视频编解码和归档格式，并记录设备、样本与明确失败边界。 |
| P1 | 依赖更新 | PR #1、#2、#4、#8、#9 检查均通过；维护者审阅适用性后再合并，合并后复核 main CI 与发布包。 |
| P1 | 性能与容量 | 在第二块 SATA 卷和局域网记录目录、搜索、并发请求、20 GiB 上传、OCR 和系统资源数据，按 [TECH 基线](TECH.md#已选性能与可靠性基线) 报告测试条件。 |
| 用户验收 | 手机体验 | 用户在实体手机验证导航、上传、阅读与 Agent 对话；浏览器窄屏检查继续作为回归。 |

## 发布门槛

通过 P0 验收，在干净主机完成安装与升级演练，复核发布包校验和、安装说明和未覆盖边界，再决定稳定版版本号及发布说明。当前服务仅面向本机或可信局域网，不提供用户认证或 HTTPS 终止。
