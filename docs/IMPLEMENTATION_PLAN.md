**当前基线：** 生产服务运行 [`80bef0a`](https://github.com/int2t05/FileSage/commit/80bef0ad92636ffda5ea17debd15f6d89b58b208)，[主线 CI 通过](https://github.com/int2t05/FileSage/actions/runs/39798600133)。Go 1.27.3 构建干净；健康、网页和文件 API 均返回 200，SQLite v30 完整性通过、外键违规为 0。远端仅有 `main`，开放 PR 为 0；服务器保留即时回退包。

## 交付状态

| 范围 | 状态 | 已验证 | 下一验收 |
| --- | --- | --- | --- |
| 文件管理与索引 | MVP 已实现 | 两块 ext4 磁盘；合成文件跨盘移动与校验；创建、保存、删除后即时可见；Shell 流式写回遇到外部写句柄时安全拒绝 | 剩余写入口的跨进程冲突与故障恢复 |
| 传输 | MVP 已实现 | 浏览器 6 MiB 上传／下载哈希一致；续传、改名、回收站及冲突有自动化覆盖 | LAN 大文件、断网与资源峰值 |
| 阅读、编辑与归档 | MVP 已实现 | 常见格式和沙箱用合成样本验证 | 真实业务文件的显示、编辑与失败样本 |
| Agent | MVP 已实现 | 持久服务真实模型生成 Shell 计划；确认后执行一步，合成文件由 `before` 变为 `after`，计划成功且样本已清理；改名、跨盘移动及同会话追问也已验证 | 其余工具的真实文件操作、并发与失败恢复组合 |
| 部署与开源 | 公开测试版运行中 | 生产运行 `80bef0a`；Go 1.27.3 干净构建、主线 CI、服务接口及 SQLite 检查通过 | 独立主机与异地恢复，再发布稳定版 |
| 手机 | 窄屏浏览器已检查 | 320／360／390 CSS px 布局 | 设备持有人用实体手机验收核心流程 |

以上“已实现”不等于稳定版验收完成；各项证据和限制见[验收范围](ACCEPTANCE.md)。
