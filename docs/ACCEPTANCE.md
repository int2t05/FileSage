# FileSage 验收范围

**状态：** MVP，尚无稳定版。**核验快照：** 2026-10-22。本文记录已验证能力、适用边界和稳定版发布前的缺项。

| 范围 | 结果 | 边界 |
| --- | --- | --- |

| 备份与恢复 | 隔离根目录和数据目录的恢复演练中，篡改并删除测试数据后恢复、重启，API 可读到原文件。服务端保留更新前的 `5a11290` 二进制和网页作为程序回退副本；另有完整恢复快照，包含 systemd、环境配置与 SQLite v29 数据副本，完整性检查通过。 | 恢复演练为同机同盘；未验证独立主机、独立备份介质、整机故障或介质损坏。 |
| 文件、传输与故障 | 合成文件验证目录操作、上传发布、重启续传、下载校验、同目录改名及审批冲突。隔离 ext4 只读、满盘、子卷卸载测试验证错误可见且原件不变；回归覆盖移动、复制、回收站、文本编辑和改名期间的并发改写。独立进程在 Agent 同卷改名提交前改写源文件时会触发冲突并恢复来源；跨卷单文件与目录移动检测已打开写句柄和快照后的已完成改写，隔离来源保留；Linux 原子覆盖在外部写句柄打开时返回冲突并保留原 inode 和外部更新。单项与批量重命名在审计记录写入后复核版本，完成后核对目标身份；Linux 测试覆盖审计期间源替换与改名返回前目标身份变化，后者记为待核查并停止后续批次。永久删除遇到审计期间同路径替换时返回冲突并保留替换项；外部写句柄打开时拒绝删除。既有关键移动与删除用例重复 20 次；本轮重命名竞态纳入 Linux 全量 Go 测试。`httpapi`／`fsroot`／trash race 和全量 `go vet` 通过。隔离内核探针确认最终租约检查后、删除目录项前仍可能有外部打开请求进入。 | Linux 租约能检测现有写句柄并阻止部分并发写打开，但无法把最后检查与 `unlink` 原子化；非协作外部进程若在该窗口打开文件，仍可能在无路径链接的 inode 上继续写入。覆盖、跨卷清理和永久删除均不承诺与外部直接访问构成全局事务。改名后的身份核对只能标记竞态结果，不能与系统调用原子绑定或保证自动恢复。其余写入口竞态和真实介质故障仍待验证。 |
| Agent | 同一会话多轮交互、计划审阅、逐步执行、`bypasspermission`、工具回执续聊、Shell 差异审计和重启恢复均有测试或隔离 E2E。照片归档、分类、重复扫描和归档操作使用合成文件完成真实模型隔离验证。2026-10-22 在持久服务的 ext4 管理卷中，以独立合成目录完成真实模型重命名 E2E：人工审阅计划后按 bypass 执行，操作成功，67 字节目标内容与样本一致；源路径消失。测试文件与目录已清理，任务和审计记录保留。 | 只使用合成数据；真实用户文件写入、其余工具类型及并发／失败恢复组合仍待验收。 |
| 性能 | 100,000 项合成目录的 NVMe 与 SATA/ext4 索引测量显示，排序索引降低目录和搜索延迟；测试条件、结果及索引空间代价见[技术基线](TECH.md#已选性能与可靠性基线)。 | 合成数据和单机结果不代表 LAN、真实文件、大文件吞吐或资源峰值。 |
| 格式支持 | JPEG、PNG；H.264 视频；PDF、文本、Markdown、CSV/TSV、XLSX，以及 DOCX、PPTX、EPUB 合成样本；ZIP、7z、TAR、TAR.GZ 和受支持的 RAR 样本。 | 相机 RAW/HEIC、复杂真实文档、音频与多种编解码器、大文件和受限 RAR 方法尚未覆盖；PPTX 为静态预览。 |

## 稳定版前待完成

- 在独立 Linux 主机演练首次安装、升级、整机重启和挂载恢复，并在独立或异地介质完成备份还原。
- 覆盖其余写入口的跨进程竞争，并验证冲突审计、恢复与原子性边界，以及真实文件恢复、只读卷、低空间和介质故障。永久删除现按确认的条目状态复核并在 Linux 普通文件上取得写租约；已确认租约和目录项检查无法与最终 `unlink` 原子化，此边界不提供与外部直接访问的全局协调保证。
- 使用真实业务样本补齐 Office、相机、音频、视频和压缩格式验证；测量 LAN、大文件上传、OCR 并发和资源峰值。
- 完成实体手机验收。
- 复核稳定版发布包和剩余验收项后再创建稳定版 Release；目前没有 GitHub Release。

FileSage 不提供用户认证或 HTTPS 终止，仅适用于本机或可信局域网。部署要求见 [Linux 部署说明](DEPLOYMENT.md)，产品范围见 [PRD](PRD.md)。
