## 稳定版前待完成

- 在独立 Linux 主机演练首次安装、升级、整机重启和挂载恢复，并在独立或异地介质完成备份还原。
- 覆盖其余写入口的跨进程竞争，并验证冲突审计、恢复与原子性边界，以及真实文件恢复、只读卷、低空间和介质故障。永久删除现按确认的条目状态复核并在 Linux 普通文件上取得写租约；Linux 最终 `unlinkat` 按名称操作，不能原子绑定已核验 inode。非协作外部进程仍可在最终检查窗口替换同名目录项，不能保证该系统调用不作用于替换项。
- 使用真实业务样本补齐 Office、相机、音频、视频和压缩格式验证；测量 LAN、大文件上传、OCR 并发和资源峰值。
- 完成实体手机验收。
- 复核稳定版发布包和剩余验收项后再创建稳定版 Release；目前没有 GitHub Release。

FileSage 不提供用户认证或 HTTPS 终止，仅适用于本机或可信局域网。部署要求见 [Linux 部署说明](DEPLOYMENT.md)，产品范围见 [PRD](PRD.md)。
