**20 GiB 上传记录：** 服务器 `Linux 7.0.0-31-generic`、i5-1135G7、ext4 NVMe `/tmp`；40 个 512 MiB TUS 分块约 11.2 MiB/s。首块后断开 SSH 隧道并重启隔离进程，续传偏移保持 `536870912` 字节。源、发布文件与服务摘要 SHA-256 均为 `11dee3489c52e22b0231195cb9e33ab886bc966e7d1c174aebe359d9c9b964ff`。另 4 路各 256 MiB 并发上传均通过哈希核验，总耗时 91.2 秒。隔离进程 `VmHWM` 为 22,476 KiB；未纳入 cgroup。测试暂存已清理。

**20 GiB 下载记录：** 通过 SSH 隧道从隔离 FileSage 实例读取第二块 ext4 卷上的预分配零内容样本。Range 返回 `206`，`Content-Range` 与总长度正确；完整 GET 返回 20 GiB，客户端 SHA-256 与源文件均为 `6cb118a8f8b3c19385874297e291dcbcdf3a9837ba1ca7b00ace2491adbff551`，耗时 1815.29 秒（11.28 MiB/s）。隔离单元 cgroup 峰值 5.41 GiB，其中文件页缓存约 5.28 GiB、匿名内存约 5.7 MiB；整机可用内存采样约 10 GiB，持久服务峰值约 6.6 MiB。测试挂载、文件、服务与隧道均已清理。该样本验证 API 流式传输与哈希，不代表高熵文件的磁盘吞吐。
