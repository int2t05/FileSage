**用途：** 对照 [PRD 第 3 节](PRD.md#L35) 与[第 6 节](PRD.md#L92)，索引当前实现、自动化测试和路线图中已有的 Linux 验收记录。本文是证据汇总，不新增测试结果或产品验收结论。

**范围与状态：** 模型超时修复提交 `71b30c1` 将 OpenAI 兼容请求上限从 30 秒调整为 90 秒。Go 全量测试、vet 及 Linux 服务器构建通过；前端 239 项测试、类型检查和生产构建在本轮变更前通过。真实 `glm-5.3-flash` 已完成隔离 Linux 浏览器 Shell 闭环，详见 `filesage-real-shell-e2e-20261018-01`。隔离模型闭环记录使用临时回环服务；源码提交 `c2800e6` 已部署为专用账户的持久 systemd 服务，并通过重启和双盘文件验收（详见 Linux QA 台账）；整机重启与持久服务上的完整模型操作未复验。历史快照不代表本次执行通过。

2026-10-18 环境复核：服务器模型环境文件目录和文件权限分别为 `700`、`600`；模型连接检查在完整应用 E2E 之前完成。服务器已有第二块独立 SSD 并挂载在用户数据卷，无需创建虚拟盘。

同日使用浏览器 viewport override 分别在 320、360、390×844 检查文件、照片、Agent、任务页（共 12 组）；document/body `scrollWidth` 均未超过 viewport，四个主导航按钮均在可视范围内，页面可切换，控制台 error/warn 为 0。320px 文件页的回收站、上传、新建文件夹按钮均完整可见。

自动化测试夹具不等同真实用户样本；390px 浏览器视口不等同实体手机；模拟模型闭环不等同远程模型验收。

## 当前提交的独立验收

环境：Linux Mint amd64，Go 1.27.2、Node.js 24.21.0、npm 11.19.0。服务和数据根目录均隔离于 `/var/tmp`，服务只监听 `127.0.0.1`，浏览器通过 SSH 隧道访问；第二块 ext4 盘以临时 bind mount 接入。所有文件均为合成测试数据。

- GitHub 固定提交源码：前端 `npm ci`、239 项测试、类型检查和生产构建通过；Linux `go test -count=1 ./...`、`go vet ./...`、主程序构建通过，健康检查返回 `ok`。
- 浏览器文件流：根目录与第二卷同时列出；Markdown 和 PDF 阅读器显示正文／页码。跨卷复制后源与副本 SHA-256 相同；跨卷移动后源路径消失、目标文件保留。
- Agent 真实模型流：中文对话生成范围确认卡，界面只列任务和路径；确认后生成单项方案，逐项批准并二次确认执行。任务完成，文件名变更且内容保留，审计记录方案、批准、执行和结果。
- 上传与下载：tus 接收后服务端状态为 `published`，任务页显示已发布；通过文件内容接口下载后，SHA-256 与本地上传样本一致。

本次服务以临时用户单元运行，未安装为持久 systemd 服务；实体手机仍由设备持有人自行验收。上述浏览器 E2E 仅对应提交 `ec1454a0…`；其后的 Shell 流程见下节。

- Linux CI 回归：归档读取和硬链接别名的 Linux 指纹／遍历差异已修正；`d556d12` 的 GitHub Actions 暴露了视频海报 stdout/stderr 管道过早关闭问题，跟进修复后先读完两个管道再调用 `Wait`。视频海报相关用例本机重复运行 50 次通过；完整 Go 检查和后续 CI 结果见[工作流记录](https://github.com/int2t05/FileSage/actions)。
- Shell 浏览器流程：隔离 Linux 服务和合成文件使用本地 OpenAI-compatible mock；命令只在副本运行，原文件哈希在审批前后保持不变。界面显示 `2 a.txt`、`3 b.txt`、`5 total`，只新增 `notes/line-counts.txt`；逐项批准和最终确认后任务成功，审计记录方案、批准、执行和结果。
- 流程文案：最终按钮与说明明确表示“写入已批准的文件变化”，因为确认步骤提交既有隔离差异，不会再次运行 Shell 命令。前端解析器也接受服务端允许的根工作目录 `.`，并添加回归测试。
- 真实模型 Shell：早期 30 秒超时导致请求失败；将 `internal/agent/chat.go` 超时调到 90 秒后，远程 `glm-5.3-flash` 浏览器闭环通过。完整提示词直连耗时 23.14 秒，网页首轮响应约 54 秒。
- 隔离服务、mock、SSH 隧道和合成测试目录均已停止并清理；未触及服务器生产服务或真实文件。
