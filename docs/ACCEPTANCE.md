## 稳定版前阻塞

- **独立恢复：** 需要另一台 Linux 主机及脱离本机的备份介质，完成安装、升级、重启、挂载和还原演练。
- **文件安全：** 补齐剩余写入口的跨进程故障测试。Linux 最终删除的名称检查与 `unlink` 无法对非协作外部进程原子化；风险边界与当前保护见 [ADR-0003](design/adr/0003-filesystem-write-safety.md)。
- **真实负载：** 补齐真实业务样本、局域网、大文件上传、OCR 并发和资源峰值测量。
- **手机：** 实体手机由设备持有人验收；当前窄屏浏览器检查已通过，状态见[项目进度](IMPLEMENTATION_PLAN.md)。

完成阻塞项后再复核发布包并创建稳定版 Release。FileSage 不提供认证或 HTTPS 终止，不应暴露到公网。
