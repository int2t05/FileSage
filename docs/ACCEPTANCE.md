## 2026-10-21 Agent 文件竞态回归

服务器隔离 Linux 环境以 Go 1.27.3 完成 `go test -race ./internal/fsroot ./internal/agent -count=1` 和对应 `go vet`。此前将文件移动、复制、回收站、文本编辑审核／逐步执行及候选清理失败 6 类回归分别重复 20 次，全部通过；复制冲突测试还重复覆盖源路径变更和目标占用场景。移动、复制和回收站用例在不同审批阶段通过已打开写句柄原地改写同一 inode，保持文件大小和修改时间不变；变更时间触发冲突，源内容保留、目标未发布或未移入回收站，并记录 stale 审计。新增的改名竞态回归在摘要校验后原地改写文件，改名提交后摘要核验失败会恢复来源；该用例以 `-race` 重复 20 次通过。跨卷摘要匹配与不匹配场景均以 `-race` 重复 20 次通过；摘要不符时来源保留且目标不发布。候选清理故障用例验证方案照常失效、清理错误可识别，结构化日志包含操作 ID、动作和错误类型，不包含源路径或暂存目录。

本轮源码在服务器 `/tmp` 的隔离副本中展开；测试使用合成文件和系统临时目录，生产服务、管理根目录和持久 QA 目录未改动。服务器 Go 1.27.3 工具链进入标准 Go 模块缓存，宿主默认 Go 仍为 1.27.2。
