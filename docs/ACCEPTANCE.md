# FileSage 验收记录

**核验日期：** 2026-10-22　**状态：** 公开 MVP，尚无稳定版 Release。下一步见[项目进度](IMPLEMENTATION_PLAN.md)。本页只记录实际验证过的范围，不代表所有主机、磁盘或文件都已验收。

| 范围 | 已验证 | 尚未验证／限制 |
| --- | --- | --- |
| CI 与构建 | 主线 `a58e695` 的 [CI 通过](https://github.com/int2t05/FileSage/actions/runs/39802320596)，包含 Go／Web 测试、race、依赖安全检查、Chromium E2E 和 Linux 发布包冒烟。 | 尚无稳定版 Release。 |
| 持久服务 | 服务器运行 `80bef0a`（Go 1.27.3）；健康、网页及文件 API 返回 200；SQLite v30 `integrity_check=ok`、外键违规为 0。管理根目录和子卷分属两块 ext4 磁盘。 | 使用合成数据；无账号密码，仅适用于可信局域网。 |
| 文件操作 | 创建、保存、删除、改名及跨盘移动用合成样本验证；Linux 独立进程回归覆盖外部写句柄冲突和部分恢复场景。 | 其他写入口竞争、真实介质故障；最终 unlink 与非协作外部进程之间仍有不可原子化的竞态，见 [ADR-0003](design/adr/0003-filesystem-write-safety.md)。 |
| 传输 | 浏览器 6 MiB 上传／下载及续传、改名、回收站、冲突自动化覆盖。2026-10-22 隔离 LAN 单次 128 MiB 测量：直传 11.54 MB/s，FileSage 上传发布 10.62 MB/s（约为基线的 92%），下载 11.84 MB/s；源与目标 SHA-256 一致，测试后生产健康检查为 200。 | 单次合成样本；未验证重复稳态、20 GiB、断网／重启、并发客户端或其他挂载卷。cgroup 峰值约 272 MiB，含文件缓存，不等同进程 RSS。 |
| 阅读、编辑与恢复 | 常见图片、文档、媒体和归档格式用合成样本检查；隔离环境与服务器本地磁盘间的备份恢复演练通过。 | 真实业务文件、复杂格式、真实整盘故障、独立主机与异地介质。 |
| Agent | 持久服务真实模型完成 Shell 计划、审批执行和同会话追问；改名及跨盘移动通过；Shell、Office、PDF、OCR 沙箱在服务约束下验证。 | 其余工具操作组合、并发与中断恢复，以及真实业务文件。 |
| 移动端 | 320／360／390 CSS px 窄屏检查。 | 实体手机验收。 |

FileSage 不提供认证或 HTTPS 终止。局域网服务具备完整文件操作能力；部署和安全边界见[部署说明](DEPLOYMENT.md)。
