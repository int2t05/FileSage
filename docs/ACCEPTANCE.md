## 格式与兼容边界

| 类别 | 已验收范围 | 尚未覆盖 |
| --- | --- | --- |
| 图片与照片 | JPEG、PNG 基本预览及拍摄日期分组样本。 | 相机 HEIC、RAW 和 FileSage 解码端点的完整浏览器流程。 |
| 音视频 | H.264 合成视频的海报与浏览器播放。 | 音频及其他编解码器的样本矩阵。 |
| 文档与表格 | PDF、Markdown、文本编辑、CSV／TSV、XLSX 的基本阅读；DOCX、PPTX、EPUB 的合成样本基本阅读。 | 复杂真实文档、公式／排版边界、EPUB 真书和大文件兼容性。PPTX 为静态页面预览，不播放动画。 |
| 压缩包 | ZIP、7z、TAR、TAR.GZ 的基本浏览、创建或解压；RAR3／RAR5 的受支持样本。 | 某些 RAR 压缩方法及多卷 RAR 会明确返回 HTTP 501，不支持读取或解压。 |

## 尚待验收

- 整机重启后的挂载与服务恢复、按[部署文档](DEPLOYMENT.md#备份与恢复)进行的隔离恢复演练、只读或卸载卷、低磁盘空间及性能基线。
- 外部进程在计划审阅、逐步写回和发布期间改动文件的完整竞争场景；服务内协调不覆盖其他进程。
- 用真实业务文件覆盖复杂 Office、相机 RAW／HEIC、音频编解码器及受限归档格式。
- 当前部署版本上，对分类、照片归档、重复项清理、压缩包操作等 Agent 流程进行完整模型与浏览器验收。
- 实体手机验收由用户完成。

FileSage 不提供用户认证或 HTTPS 终止，只适用于本机或可信局域网。部署要求和完整安全边界见 [Linux 部署说明](DEPLOYMENT.md)；产品验收标准见 [PRD](PRD.md)。

稳定版发布前，需复核本表的剩余项、执行干净主机安装与升级演练，并核对发布包校验和。
