# 稳定版验证记录

**更新：**2026-10-24　**运行候选：**服务器当前版本

候选 Go/Web CI 见[运行记录](https://github.com/int2t05/FileSage/actions/runs/40066333581)。主分支后续差异仅涉及文档与 CI，应用功能代码相同。

## 已验证

- **构建与回归：**候选 Go/Web CI 通过 Go 测试、Race、`vet`、漏洞扫描、前端测试与类型检查、生产构建、Linux 浏览器 E2E 和发布包冒烟。
- **上传：**隔离 Linux E2E 覆盖确认丢失、真实 TCP 重置及 PATCH 中途断开；续传偏移和最终 SHA-256 一致。持久服务上传／下载 E2E 通过。
- **可靠性：**限速负载 6 轮、24 个 1 GiB 文件，运行超过 1 小时且哈希全部一致。559 次 I/O 采样中 8 次超过 20%，峰值 53%，最长连续 2 次，未达到 3 次停止线。测试产物已清理，服务重启数为 0。
- **文件与恢复：**跨卷操作、SQLite 完整性、发布包重启冒烟、双物理盘备份与恢复通过；恢复后 API 可读文件。
- **Agent 与前端：**多轮会话、计划审批、Agent 步骤、Shell 变化审阅及窄屏浏览器 E2E 通过；服务端模型可用。
- **安全：**全历史 Gitleaks、路径边界、上传、归档及隔离 Shell 检查通过。公开 `main` 历史中的测试服务器地址已替换为文档保留地址；此项不等同于渗透测试。

## 已知边界

- 本服务无登录和 HTTPS，只能用于本机或可信局域网。
- 用户自行检查实体手机和真实文件样本；窄屏自动化不能替代该检查。
- 同机跨盘恢复已验证，独立 Linux 主机恢复尚未验证。
- 负载 I/O wait 有短时峰值；没有连续触发停止线。测试标准输出未保留，峰值结论来自采样记录、文件校验、停止标记和服务状态。
